El contador y su acceso

La integración opcional usa GoatCounter. El panel de estadísticas se configura para acceso exclusivo mediante la cuenta del propietario. Esta web no contiene claves de consulta, contraseñas de administrador ni un contador público. La activación y privacidad del panel requieren configurar la cuenta del proveedor.

Cuando se activa, se envía la ruta de la página sin sus parámetros ni fragmentos, y solo el dominio de procedencia. Las búsquedas de lugares, coordenadas y condiciones de las simulaciones no se envían a través de esta integración. No se añaden grabaciones de pantalla ni eventos de interacción.

Qué significa «visitas diferentes»

Son estimaciones basadas en sesiones temporales, no personas identificadas de forma permanente. Un cambio de navegador, dispositivo o sesión puede producir otra visita; los bloqueadores pueden impedir el recuento. Definición del proveedor.

Excluir este navegador

Esta preferencia se guarda localmente en el navegador. Al excluirlo se detendrá la carga del contador en futuras visitas desde este navegador. No elimina datos que ya se hayan registrado.

Alojamiento y recursos externos

La web se aloja en GitHub Pages. GitHub indica que registra direcciones IP por motivos de seguridad. Las tipografías se solicitan a Google Fonts y algunos mapas de eclipses a NASA/GSFC. Los enlaces a entrevistas y perfiles externos solo se abren al pulsarlos; no se incrustan reproductores en la portada.

El cálculo lunar y el buscador de topónimos se ejecutan en el navegador; la simulación interferométrica también. No necesitas enviar tus coordenadas ni las condiciones de los experimentos a un servidor para obtener resultados.
